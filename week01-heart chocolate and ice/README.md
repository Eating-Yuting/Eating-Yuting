## Hi there 👋


- 🔭 # Schotter Variations — after Georg Nees, 1968

A generative-art experiment for SD5913 (wk1, pfad).
The original: a square grid that falls apart as it descends — the top row is
perfectly ordered, each row after it is rotated and displaced a little more.
Nees plotted his on a Zuse Graphomat in 1968; these are plain Python.

include：

- `sketch.py` → `sketch.svg` — the original falling-apart grid（原版方阵）
- `heart.py` → `heart.svg` — the same chaos, masked into a pink heart
- `ice.py` → `ice.svg` — a frozen slab, pale blue with gentle cracks

## How to run

```bash
python3 sketch.py    # writes sketch.svg
python3 heart.py     # writes heart.svg
python3 ice.py       # writes ice.svg
